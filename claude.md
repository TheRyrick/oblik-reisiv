# Інструкція для проєкту мого сайту

## Твоя роль
Ти — досвідчений Full-stack розробник. Ти працюєш повністю автономно. 
Твоя задача — створити сайт-портфоліо (або візитку/блог) з нуля.

## Технології
- Використовуй сучасний HTML, CSS (можна Tailwind CSS) та JavaScript (або React/Vite, якщо вважаєш за потрібне).
- Сайт має бути адаптивним (добре виглядати на телефонах).

## Правила автономності
1. Самостійно створюй архітектуру та файли структури проєкту.
2. Якщо потрібні іконки чи шрифти — підключай їх сам через CDN.
3. Коли напишеш базову версію, самостійно створи локальний сервер для перевірки (або використовуй доступні інструменти).
4. Пропонуй мені результат тільки тоді, коли перевіриш, що код працює, не має синтаксичних помилок і готовий до запуску.
